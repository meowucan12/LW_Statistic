# Генератор LogS (AqSolDB)

Генератор одной случайной величины: логарифма растворимости `LogS`.

**Метод:** обратная эмпирическая функция распределения. Для отсортированной выборки \(x_{(1)},\ldots,x_{(m)}\) генерируется \(U\sim U[0,1)\), затем \(X=x_{(\lfloor mU\rfloor+1)}\). Это случайная выборка с возвращением из эмпирического распределения (bootstrap).

**Запуск:**

```bash
pip install -r requirements.txt
python generator.py AqSolDB.csv
python -m unittest test_generator.py
```

CSV должен содержать `LogS` или `Solubility` (именно логарифм растворимости). Можно задать `--n 2000 --seed 42`.

**Проверка:** 80% наблюдений используются для генератора, 20% оставляются для сравнения. Рассчитываются среднее, стандартное отклонение, медиана, квартили и критерий Колмогорова–Смирнова. Результаты: `results/generated.csv`, `results/metrics.csv`, `results/comparison.png`.

**Вывод:** метод воспроизводит эмпирическое распределение LogS, но не создаёт новые экспериментальные измерения. Близость характеристик оценивается по результатам запуска на исходном наборе данных.

Источник: Sorkun et al., *Scientific Data* (2019), https://doi.org/10.1038/s41597-019-0151-1.
